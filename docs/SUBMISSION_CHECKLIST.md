# Final Moodle submission checklist

Do not submit until every applicable item is verified.

- [ ] App opens in Android Studio with no build errors on the target emulator/device.
- [ ] Pantry Create, Read, Update and Delete have each been tested.
- [ ] Pantry records persist after the app is closed and reopened.
- [ ] There are 20 recipes stored on first run.
- [ ] Strict matching tested with one missing ingredient and one insufficient quantity.
- [ ] Plural-name matching and compatible unit conversions tested.
- [ ] All five required screens and navigation work.
- [ ] GitHub repository is accessible to the marker; at least 10 genuine incremental commits are pushed.
- [ ] `README.md` includes the app description, selected database and setup steps.
- [ ] Report uses Times New Roman 12 pt and 1.5 line spacing; Harvard citations and reference list are consistent.
- [ ] Report contains the cover information, contents, introduction, system design and data model, actual screenshots with captions, 3–5 real code snippets with explanation, 2–3 real challenges/solutions, conclusion/reflection and references.
- [ ] Every screenshot in the report was captured from the actual running app; no placeholder screenshots or mockups are used as evidence.
- [ ] Report includes the working GitHub URL, personal details and signed originality declaration.
- [ ] Video is narrated, 5–7 minutes, readable, and demonstrates GitHub history, CRUD, strict matching, persistence, code concepts and SQLite justification.
- [ ] Video is an MP4 placed directly in the submission ZIP.
- [ ] ZIP filename follows `Studentnumber_Surname_MobileAppDev700_Assignment.zip`.
- [ ] Report file follows `Studentnumber_Surname_MobileAppDev700_Assignment.docx` (the brief describes a Word/PDF report but gives this DOCX filename).
- [ ] Single ZIP contains complete project source, video and final report and is no larger than 50 MB.
- [ ] Archive opens correctly and contains no unnecessary `build/` or `.gradle/` cache folders.
